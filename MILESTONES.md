# Milestones

Tags are annotated, immutable, and created only after implementation and acceptance tests pass.

- `v0.1.0-core` — domain model, artifact provenance, SQLite schema/store, transactional monotonic IDs, state transitions, migrations, and acceptance tests.
- `v0.2.0-git` — isolated worktrees and validated patch-to-commit transactions.
- `v0.3.0-daemon` — durable daemon, Unix protocol, event streaming, and recovery.
- `v0.4.0-fake-harness` — harness contract and deterministic end-to-end fake adapter.
- `v0.5.0-pi` — Pi adapter with local and remote model compatibility.
- `v0.6.0-adk` — Google ADK adapter and initial agent workflow.
- `v0.7.0-multi-harness` — interchangeable role policies and cross-harness execution/review.
- `v1.0.0` — stable durable orchestration contract.
