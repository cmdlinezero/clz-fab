# FAB

FAB is a durable, harness-agnostic orchestration daemon for software-engineering agents.

The project is being built from a deterministic core outward: durable tasks and artifacts, immutable provenance, single-outcome patches, validation, Git transactions, then interchangeable agent harnesses such as Pi and Google ADK.

See `DESIGN.md` and `MILESTONES.md` for the current architecture and delivery plan.
